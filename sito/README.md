# Gabetti Gruppo ADG

Crea una landing page mobile-first per un'agenzia immobiliare (Gabetti Franchising) finalizzata all'acquisizione di mandati di vendita immobili. L'obiettivo è far compilare un form multi-step da parte di proprietari di casa che vogliono ricevere una valutazione gratuita del loro immobile.

## BRAND IDENTITY

- Nome brand: Gabetti Franchising | Gruppo ADG

- Logo: usa il file logo caricato (sfondo nero, scritta "gabetti" in rosso bordeaux + "FRANCHISING" in grigio sotto)

- Colori principali:

  - Rosso Gabetti: #B20933 (primario, per CTA, accenti, headline)

  - Grigio Gabetti: #4C565C (secondario, per testi, bordi, footer)

  - Bianco: #FFFFFF (sfondo principale)

  - Nero: #000000 (header dove va il logo)

  - Grigio chiaro: #F5F5F5 (sfondi sezioni alternate)

- Font: Inter o Manrope (sans-serif moderno, leggibile)

- Stile: pulito, professionale, fiducia, no fronzoli, mobile-first

### Eventi dataLayer da pushare

Su ogni interazione chiave la pagina deve fare un push nel dataLayer di Google Tag Manager. Implementa questi eventi:

1. **All'apertura della pagina** (automatico via GTM)

2. **Quando l'utente passa allo Step 2 del form**:

```javascript

window.dataLayer = window.dataLayer || [];

window.dataLayer.push({

  event: 'form_step_1_completed',

  form_name: 'valutazione_immobile',

  step: 1

});

```

3. **Quando l'utente passa allo Step 3 del form**:

```javascript

window.dataLayer.push({

  event: 'form_step_2_completed',

  form_name: 'valutazione_immobile',

  step: 2

});

```

4. **Al submit completato del form (prima del redirect a /grazie)**:

```javascript

const eventId = 'lead_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);

window.dataLayer.push({

  event: 'lead_submitted',

  form_name: 'valutazione_immobile',

  event_id: eventId,

  user_data: {

    email: emailValue,

    phone: phoneValue,

    first_name: firstNameValue,

    last_name: lastNameValue,

    city: cityValue,

    zone: zoneValue,

    property_type: propertyTypeValue,

    timeline: timelineValue

  },

  value: 50,

  currency: 'EUR'

});

```

Salva l'eventId in sessionStorage prima del redirect.

5. **Sulla Thank You Page /grazie**:

```javascript

window.dataLayer.push({

  event: 'lead_confirmed',

  event_id: sessionStorage.getItem('lead_event_id')

});

```
